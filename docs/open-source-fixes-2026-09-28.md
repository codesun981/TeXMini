# 开源前问题修复与验证

本次按照开源前审查的 12 项问题修复，保留原有编译、编辑、PDF 和项目切换流程。下表记录具体修复及对应回归；不是对所有系统、TeX 宏包或所有输入的无缺陷保证。

| 项 | 原问题 | 修复与验证 |
| --- | --- | --- |
| 1 | 清理误删 `.ist/.xdy` 样式 | 从辅助文件集合移除；清理服务仅删已知普通文件，保留目录、符号链接、PDF 和未知文件。文档与清理回归覆盖。 |
| 2 | 部分 `.bib` 缺失仍删除 `.bbl` | 必须确认所有直接声明的数据库可读；存在宏展开或其他输入依赖时保守保留。源目录、输出目录、辅助目录、历史缓存及子文件分别保护。 |
| 3 | 同时间戳替换逃过外部变更检查 | 记录设备、inode、大小、mtime、ctime；保存前核对。后台重新读取并保留正确编码，冲突只接受提示时读到的版本；切换、关窗使旧回调失效。 |
| 4 | 回车重复插入已有 `\end` | 按全文真实环境配对，区分嵌套、注释、原样文本、光标位置。回车和环境补全共用判断。 |
| 5 | 旧编码读成乱码、保存改变编码 | 无损解码和原编码保存；有效声明变化时无损转换，未知或不能表示的字符明确报错。编译、项目推断、状态栏采用同一解码入口。 |
| 6 | 保存失败仍编译旧磁盘内容 | 正式保存、暂存保存失败立即返回；保留未保存状态及原诊断，不启动编译。真实控制器替身测试覆盖。 |
| 7 | 自定义输出目录或 jobname 指向旧 PDF | 输出路径统一解析，支持别名、独立参数值、空格、绝对/相对目录、`%A`；预览和清理使用相同路径。真实 latexmk 与直接引擎测试覆盖已有/不存在目标 PDF。 |
| 8 | 不同目录的同名子文件选错主文件 | 以完整路径追踪输入关系及 import 上下文；循环有界、明确歧义时不随机选择，保留魔法 root 和原有单候选回退。 |
| 9 | 关闭项目后空白首页覆盖恢复记录 | 关闭后的占位文档不写入会话；真正新建仍清空旧会话。测试覆盖关闭后再次保存会话及新建文档。 |
| 10 | 块类型不变但边界移动时漏刷高亮 | 对齐编辑前后的语法区间，仅扩大实际受影响范围；约 250 种编辑组合验证所有保留字符的分类变化都被覆盖。 |
| 11 | 大量未闭合标题导致平方级扫描 | 首次失败时建立未配对括号索引，后续跳过重复后缀扫描；20,000 个残缺标题及末尾有效标题回归通过。 |
| 12 | 构建二进制要求 macOS 15，与声明不符 | 编译和链接都固定 macOS 14；参数、工具链、架构、源清单变化使旧对象失效，验证 Mach-O 和 Info.plist 一致。 |

相关边界一并修复：原样环境在文件末尾多算一个字符的越界；清理等待被丢弃的编译任务真正排空，清理期间暂缓新编译，切换或取消后不执行旧重试。所有清理及参考文献检查在后台完成。

## 自动验证

使用 `make test` 运行 Foundation/CoreText 单元测试、真实 TeX 集成测试和不创建窗口的控制器测试。控制器测试执行生产代码，使用替身提供编辑文本、磁盘读取门禁、保存失败和冲突选择，不驱动 GUI。

原审查基线为 125 项单元测试。本次最终验证在 macOS 15.1 / arm64 完成：

- `make test`：168 项单元测试通过，0 失败；真实 TeX 集成测试通过；控制器流程回归通过。
- `./build.sh`：构建通过；再次构建未重编源文件，增量判断正常。
- `vtool -show-build` 与 Info.plist：最低系统版本均为 14.0。
- `codesign --verify --deep --strict`、脚本语法、plist 和 `git diff --check`：通过。
- `.app/Contents/Resources/` 中的项目许可和第三方许可与仓库内容一致。

真实 TeX 集成测试必须能写入当前用户缓存目录；在限制缓存写入的沙箱中会触发回退，因而“辅助文件只在缓存”断言不适用。最终结果来自具备正常缓存权限的运行。

扫描器性能对比（同机优化构建，单次测量，非跨机器指标）：

| 输入 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 2,000 个未闭合标题 | 约 39 ms | 约 2.1 ms |
| 4,000 个未闭合标题 | 约 150 ms | 约 1.8 ms |
| 8,000 个未闭合标题 | 约 594 ms | 约 3.5 ms |

## 人工冒烟步骤

1. 打开中文模板和普通英文项目，编译、取消、再次编译；检查 PDF、错误行跳转和 SyncTeX 双向定位。
2. 在项目 A 制造编译错误，然后切换项目 B、同文件夹其他 TeX、无主文件的文件夹；检查日志、错误标记、预览和字体建议均属于当前文档。
3. 在现有 `\begin{document}` 后回车，不应增加第二个结束标记；新增未闭合环境仍自动补全。移动 verbatim 结束标记，检查跨空行颜色更新。
4. 修改已打开文件，同时在外部替换磁盘文件；分别选择重新载入、保留更改，检查内容和未保存标记。只读目录下保存并编译应报错并保留编辑内容。
5. 打开带明确编码声明的 GBK/Latin-1 文件，编辑保存再打开；检查中文/重音字符。未知编码应提示转换，不能写回乱码。
6. 设置自定义 outdir/jobname，编译、导出、正反向跳转并清理；确认 PDF 对应当前编译，样式、未知文件及不可再生 `.bbl` 留存。
7. 关闭项目进入首页后退出并重开，应恢复项目与光标；真正新建未命名文档后退出不应恢复旧项目。
8. 在编译或清理期间切换文档、继续编辑、再次编译及取消，检查没有旧任务回调、意外重试或文件互相覆盖。

## 范围与开源材料

编码检测不猜测任意未声明的旧字符集；复杂 TeX 宏生成的输入关系仍建议用 `% !TEX root` 指定。磁盘指纹与 Foundation 原子写用于检测常见外部修改，不是多个进程之间的事务锁。清理对无法证明可重建的参考文献保守保留，可能留下部分辅助文件。

自动测试不替代实际界面冒烟或 macOS 14/Intel 机器验证。构建默认针对本机架构；本次仅核对最低系统元数据，未制作 Universal 发行版。

仓库补充 MIT `LICENSE`、中文 `README.md` 和 `THIRD_PARTY_NOTICES.md`，构建产物中同时包含项目和 SyncTeX 许可声明；本次未发布发行包。
