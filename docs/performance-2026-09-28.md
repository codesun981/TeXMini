# 首批性能优化与验收记录

优化前工作区已保存为 `ec387e4`。本批只调整行号计算、补全索引及大纲解析的工作方式，没有增加运行时依赖，也未改变编译、保存、模板或 PDF 功能。

## 改动

- 编辑器光标与行号尺共用不可变 `TMLineIndex`；字符修改后重建，字体和颜色变化不失效。保留 UTF-16 列位置和 `\n` 行号规则，原有跳行流程保留。
- 补全按文件路径与文件指纹缓存符号，保存只使对应文件失效。磁盘扫描与符号提取在串行后台队列执行；当前未保存内容覆盖同一路径的磁盘符号。上下文过滤、排序、60 条上限与编码回退保留。
- 异步候选核对文本修订号、文档、选区及窗口焦点。取消、文件切换和输入法组字后丢弃旧结果。最新候选未就绪时，导航与确认按键交回正常编辑，不排队或吞键。
- 大纲使用高亮已生成的扫描及共享行号索引。必要时先完成待处理高亮，保留原来的块结构变化检测；跨文件类型加载时先设置新语法，再给新正文着色。

## 本机基准

均为 `clang -O2`、预热后多次中位数，不包含 AppKit 排版、绘制或完整输入事件。输入基准与 `ec387e4` 的大纲实现／原光标循环对照。

| 场景 | 原逻辑 | 优化后 |
|---|---:|---:|
| 约 1 万行大纲构建（110 万 UTF-16 字符） | 14.49 ms | 0.21 ms，复用扫描与行号索引 |
| 约 5 万行大纲构建（551 万 UTF-16 字符） | 69.64 ms | 1.06 ms，复用扫描与行号索引 |
| 5 万行末尾附近光标行列查询 | 36.48 ms | < 0.01 ms，索引已建立 |
| 5 万行索引重建 | — | 2.72 ms，每个字符版本最多一次 |
| 400 文件／17 MB 项目，缓存命中的命令补全 | 12.21 ms | 0.15 ms |
| 同项目，全局索引失效后的查询 | 453.02 ms | 7.57 ms，文件指纹未变 |
| 同项目，单文件保存失效后的查询 | — | 8.69 ms，后台执行 |

大纲构建取 9 次中位数；光标／索引取 21 次。补全为 `\em` 查询，当前文件约 1 万行／830 KB，文件系统热缓存；失效查询取 7 次、命中取 21 次。首次建立项目索引仍需读取文件，其成本移到了后台，不能用热缓存数字代表冷启动。完整语法扫描仍存在，本批消除的是大纲的重复扫描。

## 人工验收步骤

遵循仓库约定，未驱动 GUI 自动截图或点击。以下交互需在应用中人工确认：

1. 打开较长文档，在末尾输入、删除、粘贴多行，切换自动换行；确认行列、行号、大纲和跳转一致。
2. 输入 `\cite{`、`\ref{`、`\begin{` 及命令，确认候选出现后方向键、Tab、回车、环境闭合与撤销／重做正常。
3. 请求补全后立即 Esc、点击其他位置、切文件、打开设置或切换应用；旧候选不能重新出现。索引首次加载时连续输入不能丢字或吞回车。
4. 中文输入法组字时使用方向键、回车、Esc；补全不能抢输入法按键。
5. 新增／删除 label，另存或重命名文档，再触发补全；候选以当前正文为准。
6. `.tex → .md → .tex → 空文档` 连续切换，并编辑跨行公式／verbatim 边界；确认颜色、大纲和行号属于当前文本。
