# 10 · 大文档性能

**目的**："极速"是否成立。`big.tex` 约 6000 行、80 节 240 小节 240 个公式，由 `generate.py` 生成（想更大就把 `range(1, 81)` 改大再跑）。

## 步骤
1. 打开 `big.tex`，计时到可编辑（应 < 1 秒，语法高亮全文完成 < 2 秒）。
2. 按住 ⌘↓ / 滚轮快速滚到底再滚回来，观察掉帧。
3. 在文档中部随便打字、删字，观察输入延迟；行号槽是否跟得上。
4. ⌘L 跳到 3000 行。
5. ⌘B（pdflatex 两遍约 5–10 秒），期间继续打字，确认编辑不被阻塞。
6. 编译完成后 ⌘J，再在 PDF 末页双击。
7. 在末尾 `\ref{` 里 ⌃Space，看补全弹出的延迟（要扫描 480 个 label）。
8. ⌘F 查找 `Subsection 40.2`，查找栏应即时高亮。
9. 打开"大纲"，展开/折叠，点击第 60 节。
10. 关掉自动换行（⌥⌘W）再打开，观察重排时间。

## 预期
- 以上每一步无明显卡顿（> 300 ms 的停顿都记下来）。
- 编译期间 UI 可用，取消（⌘.）立即生效。
- 内存不异常增长（活动监视器看一眼即可）。

## 记录
- 各步骤主观耗时；如果某步卡，记录是滚动、高亮、大纲还是补全。
