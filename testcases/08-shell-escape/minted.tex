\section{minted: shell escape and Pygments}
On TeX Live 2025+ minted 3 runs its helper \texttt{latexminted} under
\emph{restricted} shell escape, so this file compiles even with Allow Shell
Escape unchecked. On older minted 2.x it fails with "You must invoke LaTeX with
the -shell-escape flag" until the option is enabled. Test both states and
record which you get.

Either way Pygments must be reachable: TeXMini injects /Library/TeX/texbin,
/usr/local/bin and /opt/homebrew/bin into PATH. A pygmentize that only lives in
an Anaconda prefix is not found by TeX; if highlighting fails, note that as a
"custom PATH in preferences" request.

\begin{minted}{python}
def hello(name: str) -> str:
    return f"Hello, {name}!"
\end{minted}

A \texttt{\_minted*/} cache directory appears next to this file; the file
browser must hide it (it starts with an underscore, not a dot) or at least not
show its hundreds of cache files.
