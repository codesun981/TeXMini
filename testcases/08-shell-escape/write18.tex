\section{write18 probe}
% 下面这行在 -shell-escape 关闭时会被 TeX 拒绝并给出 warning：
% "runsystem(...)...disabled" ；开启后会生成 shell-escape-ok.txt。
\immediate\write18{echo shell-escape-works > shell-escape-ok.txt}

\IfFileExists{shell-escape-ok.txt}{%
  \textbf{shell-escape is ON}: the file shell-escape-ok.txt was created.%
}{%
  \textbf{shell-escape is OFF}: nothing was written (this is the safe default).%
}

\section{How to test}
1. First build with Compile > Allow Shell Escape \emph{unchecked}: the PDF must say OFF
and the raw log contains "runsystem ... disabled". Build succeeds.

2. Check Allow Shell Escape (also visible in Cmd-Comma preferences), rebuild: PDF says ON
and \texttt{shell-escape-ok.txt} appears in the file browser? (It has a .txt
extension so it should be listed as an editable file.)

3. Uncheck again, run Clean and Rebuild (Opt-Cmd-B), delete shell-escape-ok.txt by hand:
back to OFF.
