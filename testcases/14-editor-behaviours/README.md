# 14 · 编辑器行为演练场

**目的**：不编译，只测打字手感：自动配对、环境自动闭合、缩进、注释切换、补全、括号匹配、跳行、查找替换。

## 步骤
打开 `typing-playground.tex`，从上到下按每段 `%` 注释里的说明操作。

## 预期
每条注释即预期。另外：
- 所有编辑动作都可 ⌘Z 逐步撤销。
- 补全弹窗用 ↑↓ 选、回车确认、Esc 关闭；确认后光标在 `}` 之前。
- 光标在 `{` 旁时配对 `}` 高亮，移开后取消；选区非空时不高亮。
- 字数统计随输入变化。

## 记录
- 哪些自动行为让你觉得"多管闲事"（例如输入 `$` 自动补 `$` 在打价格时）。
