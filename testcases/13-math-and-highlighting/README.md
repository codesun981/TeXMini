# 13 · 数学与语法高亮边界

**目的**：只看编辑器着色，不看 PDF。逐节核对颜色：命令蓝、环境紫、数学橙、verb 青、注释灰斜体、正文默认。

## 步骤
1. 打开 `highlight-torture.tex`，先不编译，逐行看颜色。
2. 在 "Inline math edge cases" 一节里删掉一个 `$` 再打回去，看重新着色是否只影响本段且正确。
3. 在 `gather` 环境的空行里打字，看颜色是否错乱；⌘/ 注释掉整节后编译。
4. 在 `align*` 里那行注释后面打字。
5. ⌘A 全选 → ⌘] 缩进 → ⌘[ 还原，看高亮是否全文正确。
6. 把字号 ⌥⌘= 放大三次再 ⌥⌘0 恢复，看颜色不丢。

## 预期
- 文件内每一行注释说明了应有的颜色；不符合的记录行号。
- 已知限制：`verbatim` / `lstlisting` 环境体没有特殊处理，可能把 `$` `%` 当数学/注释，记录严重程度。
- 段落级增量高亮：跨空行的数学环境是已知弱点，看实际表现是否可接受。
