# 02 · 中文 ctex 文档

**目的**：中文用户的第一印象。引擎自动选择、字体、字数、大纲中文、SyncTeX 在 CJK 下的精度。

## 步骤
1. 打开 `report.tex`，状态栏引擎保持"自动 (latexmk)"。
2. ⌘B。
3. 看状态栏字数；在"字数统计"一节里多打几个汉字，观察数字。
4. 双击"SyncTeX 与中文"那一行；再在 PDF 对应段落双击。
5. 把状态栏引擎手动切成 pdflatex 再 ⌘B（预期失败），再切回自动。

## 预期
- 自动模式下状态栏显示 `latexmk · xelatex`，编译成功，PDF 中文正常。
- 大纲显示中文章节名。
- 字数统计对中文有合理数值（macOS 分词会把连续汉字按词切分）。
- 手动 pdflatex 时应报错并在问题列表里出现错误；切回自动后重新编译成功。
- CJK 行的 SyncTeX 定位误差不超过一两行。

## 已知/待观察
