# 05 · 警告与坏盒子（编译成功但有问题）

**目的**：成功编译时的问题呈现：警告计数、坏盒子计数、问题页按类型着色、行号。

## 步骤
1. 打开 `warnings.tex`，⌘B（首次编译 latexmk 会跑多遍，最终仍成功）。
2. 看状态栏：`✓ 编译完成 · N 警告 · M 坏盒子`，颜色为橙色。
3. 打开日志抽屉"问题"页，逐条点击。
4. 修掉 `sec:nope` → `sec:one`，⌘B，看警告数减少。

## 预期
- 问题页里：警告为橙色，坏盒子为黄色，没有错误行。
- undefined reference / citation 警告有 `on input line N` 解析出的行号，点击能跳。
- "Label multiply defined" 警告能跳到第二个 `\label{sec:one}` 附近。
- Overfull hbox 有 `at lines N--M` 的行号，点击跳到 N。
- 编译成功时抽屉**不**自动弹出（只有失败才弹）。
- 行号槽对应行有橙/黄点；同一行同时有警告和坏盒子时显示更严重的橙色。

## 记录
- 警告消息被 TeX 79 列折行时，问题列表里的文本是否完整拼接。
