# 16 · 拼写与语法（系统检查）

**目的**：macOS 自带拼写检查在 LaTeX 源码里的表现，以及菜单入口是否齐全。

## 步骤
1. 打开 `prose.tex`。
2. 编辑 ▸ 拼写和语法 ▸ 输入时检查拼写：勾选后错词下应出现红色波浪线。
3. ⌘; 逐个跳到下一个错词；⌘: 打开拼写面板，改一个。
4. 勾选"随拼写检查语法"，看 Grammar 一节是否有绿色波浪线。
5. 右键错词看建议。

## 预期
- 菜单项在编辑器有焦点时可用，勾选状态正确显示。
- `\textbf`、`\emph` 这类命令名会不会被标红？（系统检查不认识 LaTeX，很可能会。记录：是否需要在检查前剔除 `\command`、`\cite{}`、`\ref{}` 参数与数学）
- 语言：系统默认（自动）；在拼写面板里切换语言是否生效。

## 记录
- 命令名和 label 被标红的噪音程度；如果不可接受，这就是"LaTeX 感知的拼写检查"需求。
